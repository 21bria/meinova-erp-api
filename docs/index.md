# ERP Knowledge Base

Selamat datang di portal dokumentasi ERP.

Dokumentasi ini menjadi single source of truth untuk visi produk, arsitektur, modul, UI/UX, API, database, deployment, dan standar pengembangan.

## Main Concept
ERP ini dirancang sebagai **Intelligent Digital Workspace**, bukan hanya sistem input transaksi. Fokus utama adalah personal workspace, workflow, task inbox, dashboard customization, AI assistant, dan integrasi operasional industri.

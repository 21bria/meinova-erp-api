# Organization Setup Workflow

Sebelum menggunakan HR maupun modul lainnya, struktur Organization harus dibuat terlebih dahulu.

```
Company
    │
    ▼
Branch
    │
    ▼
Site
    │
    ▼
Division
    │
    ▼
Department
    │
    ▼
Section
    │
    ▼
Position
    │
    ▼
HR Employee
```

Setelah Employee dibuat, struktur ini akan digunakan oleh:

- Payroll
- Leave
- Attendance
- Asset Assignment
- Inventory Request
- Approval Workflow
- Finance
- Mining

## Notes
Dokumen ini akan diperbarui seiring pengembangan fitur.

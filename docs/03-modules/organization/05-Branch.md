# Branch

Branch adalah cabang administrasi perusahaan.

Tidak semua perusahaan memiliki Branch.

Jika hanya memiliki satu kantor pusat, cukup buat:

Head Office

Jika memiliki beberapa wilayah:

Jakarta Branch

Balikpapan Branch

Morowali Branch

Branch digunakan untuk kebutuhan administrasi dan operasional regional.
